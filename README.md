# MATFFT-CP

Reserved repository for the planned open-source release of MATFFT-CP.

This repository currently contains directory placeholders only. No software implementation, manuscript, simulation results or measured EBSD data are included. The software is planned for release after manuscript acceptance; the release license and documentation will be provided with that release.

## Planned organization

- `src/` — software implementation
- `docs/` — user and developer documentation
- `examples/` — usage examples
- `tests/` — software checks
- `assets/` — distributable project assets
- `.github/` — repository configuration

These directories are reserved, not a final or runnable software layout.
